# Nano Banana Helper 2.0

Nano Banana Helper 2.0 expands the app from a Gemini batch workbench into a multi-provider image generation and editing tool with first-class OpenAI provider support, stronger recovery, and clearer result inspection.

## Highlights

- **OpenAI is now a first-class provider**: switch between Gemini and OpenAI in Settings, store separate API keys, and use provider-specific model defaults.
- **GPT Image 2 support**: generate from text, edit existing images, use masks, select output format, tune background handling, choose input fidelity, set compression, and request up to 4 images from one OpenAI request.
- **OpenAI Batch Tier**: the existing Batch Tier toggle now works with OpenAI through the OpenAI Batch API for non-urgent high-throughput work.
- **Better remote recovery**: OpenAI remote batch IDs and request IDs are persisted so failed or stale OpenAI jobs can be resumed from History or Project Gallery.
- **Safer output writes**: if the selected output folder is unavailable after a provider returns images, the app saves them into `Recovered Outputs` under application support instead of dropping the returned data.
- **Cleaner results review**: the result detail popup now shows full-resolution output with generation metadata, prompt/system prompt, model, ratio, size, and tier details.

## What Changed

### Providers and Models

Version 2.0 adds a provider picker in Settings. Gemini remains available, and OpenAI can now be configured with its own API key and bundled `gpt-image-2` model default.

### OpenAI Generation and Editing

OpenAI workflows support text-to-image, image edits, masks, multi-input edits, OpenAI output formats (`PNG`, `JPEG`, `WebP`), transparent or opaque backgrounds where supported, input fidelity, compression, and images per request.

### Batch Tier

Batch Tier now maps to the selected provider:

- Gemini uses Gemini `batchGenerateContent`.
- OpenAI uses the OpenAI Batch API with remote batch/request tracking.

OpenAI batch results support partial success, cancellation reconciliation, idempotent result replay, and resume from persisted history.

### Usage and Pricing

The app now handles Gemini per-image pricing and OpenAI token-based pricing. OpenAI preflight estimates are approximate until returned token usage is available after completion.

### Reliability

The queue recovery path now handles stale cancellation rows, security-scoped output folders, and returned output bytes more defensively. When the primary output folder fails, completed images are written to an app-controlled recovery folder.

## Upgrade Notes

- Existing Gemini configuration continues to load through the legacy config migration path.
- Add an OpenAI API key in Settings before selecting OpenAI workflows.
- OpenAI costs are based on provider-reported token usage after completion; estimates shown before completion may differ from final tracked usage.
- Download `Nano Banana Helper.dmg` from this release and drag the app into Applications.
